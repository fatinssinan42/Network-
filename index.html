How to Use This Library

  1. Learn the core concepts.
  2. Use packet and tool evidence to validate understanding.
  3. Complete at least one lab.
  4. Write a short troubleshooting note with findings.

Layer 1 — Physical

Learn

  • Signal basics: electrical, optical, radio.
  • Bandwidth vs throughput vs latency vs jitter.
  • Attenuation, interference, duplex/negotiation basics.

Tools

  • ping, ethtool, ip -s link

Lab Ideas

  • Compare gateway vs public host latency/loss.
  • Test duplex/speed changes in a simulator.
  • Compare wired vs Wi-Fi consistency.

Layer 2 — Data Link

Learn

  • Frames, MAC addressing, ARP, VLANs, trunks.
  • Broadcast domains and loop prevention basics.

Tools

  • Wireshark filters: arp, eth.addr, vlan
  • arp -a, ip neigh

Lab Ideas

  • Capture ARP request/reply behavior.
  • Build isolated VLANs and verify expected limits.
  • Diagnose a trunk mismatch in simulation.

Layer 3 — Network

Learn

  • IPv4 subnetting/CIDR, routing, default gateway logic.
  • IPv6 basics, ICMP diagnostics, NAT behavior.

Tools

  • ip addr, ip route, traceroute/tracert
  • Wireshark filters: ip, ipv6, icmp

Lab Ideas

  • Subnet a small office topology.
  • Break/fix default gateway and routes.
  • Compare path changes with traceroute.

Layer 4 — Transport

Learn

  • TCP handshake/teardown and reliability behavior.
  • UDP tradeoffs and port/service mapping.

Tools

  • ss, netstat, nc, telnet
  • Wireshark filters: tcp, udp

Lab Ideas

  • Compare TCP/UDP behavior under packet loss.
  • Validate open/filtered/closed ports.
  • Classify timeout vs reset scenarios.

Layers 5–7 — Session, Presentation, Application

Learn

  • Session continuity and token handling.
  • Encoding, encryption, compression concerns.
  • DNS, HTTP/HTTPS, SMTP, SSH, DHCP fundamentals.

Tools

  • dig, nslookup, curl -v, openssl s_client
  • Browser dev tools and Wireshark dns/http/tls filters.

Lab Ideas

  • Trace DNS → TCP → TLS → HTTP flow.
  • Break DNS resolver settings and diagnose.
  • Test certificate-name/expiry failures in lab.

Cross-Layer Security

  • Map threats and controls across L2, L3/4, and L7.
  • Use segmentation, least privilege, and logging.
  • Create a threat-to-control matrix with residual risk.

Capstone Resource Kit

  • No internet on one host.
  • Ping works but web access fails.
  • High latency/jitter for voice/video.
  • Intermittent DNS/TLS failures.

Deliverables: symptom summary, layered test sequence, evidence table, root cause, corrective and preventive actions.
